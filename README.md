# VanBora

**Conectando famílias e motoristas de transporte escolar.**

O VanBora é um projeto desenvolvido por estudantes do primeiro semestre de Análise e Desenvolvimento de Sistemas da Fatec Araçatuba, para o Ideathon 2026.

## Como surgiu a ideia

Encontrar uma van escolar nem sempre é fácil. Muitas famílias procuram em grupos de WhatsApp, redes sociais ou por indicação. Mesmo quando encontram um motorista, ainda precisam descobrir se ele atende à escola, passa perto de casa, tem vaga e consegue chegar no horário.

Os motoristas também têm dificuldade para encontrar novos alunos que estejam no caminho de suas rotas.

Foi pensando nesses problemas que criamos o VanBora.

## Nossa proposta

O VanBora busca facilitar o encontro entre famílias que precisam de transporte e motoristas que oferecem esse serviço.

A família informa onde mora, a escola ou faculdade, o horário e se precisa de ida, volta ou ambos.

A proposta é mostrar opções que façam sentido para aquele trajeto, ajudando a comparar caminhos, horários e informações dos veículos.

Também desenvolvemos um ambiente para os motoristas organizarem veículos, passageiros e rotas.

## O que desenvolvemos

**VanBora Famílias**

É a parte em que as famílias pesquisam opções de transporte. Para demonstrar seu funcionamento, utilizamos motoristas fictícios e serviços de mapas que ajudam a localizar endereços e calcular percursos pelas ruas.

Assim, mostramos como a busca poderia funcionar, mesmo sem uma rede de motoristas reais disponíveis.

**VanBora Motoristas**

É o ambiente criado para ajudar os profissionais a organizar o trabalho. Ele reúne recursos para cadastrar veículos, montar rotas, organizar paradas e passageiros e planejar trajetos.

Algumas funcionalidades já foram desenvolvidas, enquanto outras ainda precisam de ajustes e testes.

## Ferramentas utilizadas

- **React e TypeScript:** para criar as telas e programar as funcionalidades.
- **Vite:** para desenvolver e preparar o aplicativo.
- **Tailwind CSS:** para organizar a aparência das páginas.
- **Supabase:** para armazenar informações e gerenciar o acesso dos usuários.
- **Serviços de mapas:** para localizar endereços e calcular trajetos.
- **GitHub:** para guardar o código e acompanhar as alterações.
- **Vercel:** para publicar o aplicativo na internet.

Também utilizamos **ferramentas de inteligência artificial como apoio ao desenvolvimento**.

Como estamos no primeiro semestre de ADS, ainda estamos aprendendo muitas dessas tecnologias. A IA nos ajudou a escrever e corrigir códigos, desenvolver telas, identificar problemas e trabalhar com ferramentas como o GitHub, o Supabase e a Vercel.

Com esse apoio, conseguimos transformar nossa ideia em um protótipo mais completo, mesmo estando no início do curso.

As decisões sobre a proposta e as funcionalidades foram orientadas por nós, com auxílio da IA na parte técnica.

## Como executar o projeto

Para executar o VanBora no computador, é necessário instalar o Node.js.

Depois de baixar o repositório, abra a pasta do projeto e execute:

```bash
npm install
npm run dev
```

Para verificar a compilação do projeto:

```bash
npm run build
```

Para executar os testes automatizados:

```bash
npm run test
```

Algumas funcionalidades precisam de configurações adicionais para funcionar.

## Em que fase estamos

O VanBora ainda é um protótipo acadêmico, não um serviço comercial de transporte.

Já construímos diferentes telas, funcionalidades e integrações, mas ainda precisamos concluir melhorias e realizar mais testes.

A pesquisa das famílias utiliza dados fictícios para demonstrar a proposta. Isso significa que os motoristas, preços e vagas apresentados não representam ofertas reais.

Nosso objetivo é mostrar como a tecnologia pode ajudar a resolver um problema do dia a dia e como conseguimos aplicar, na prática, o que estamos começando a aprender no curso.
