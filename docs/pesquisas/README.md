# Pesquisas do Grupo — Vambora

Esta pasta guarda a pesquisa real da equipe. **Cada colega preenche e faz commit com a própria
conta** — isso conta como contribuição autêntica no Ideathon (código não é a única forma de
contribuir).

## Regra de ouro

**Não invente** pesquisas, números, respostas ou fontes. Se não confirmou, marque como
`pendente de verificação`. Sempre registre **fonte, data, autor, método, evidência e limitações**.

## Pastas

| Pasta | Para quê |
|---|---|
| `escolas-inep/` | Importação de escolas do Censo/INEP (código, fonte, data) |
| `documentacao-aracatuba/` | Requisitos legais do transporte escolar (municipal/estadual/federal) |
| `entrevistas-familias/` | O que as famílias precisam e sentem |
| `entrevistas-motoristas/` | O que motoristas/operadores precisam |
| `precos/` | Faixas de preço praticadas na cidade |
| `concorrentes/` | Como outras soluções resolvem (ou não) |
| `mobilidade-sustentabilidade/` | Impacto em mobilidade e sustentabilidade |
| `fontes/` | Lista central de fontes e links |
| `validacao-lgpd/` | Pontos de LGPD e proteção de menores |
| `campanha-interesse/` | Campanha de pré-lançamento (coleta mínima, com aviso de privacidade) |
| `resultados-testes/` | Resultados de testes com usuários |
