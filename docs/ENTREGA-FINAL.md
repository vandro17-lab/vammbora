# Apresentação e entrega — VanBora

## O que estamos apresentando

O VanBora é um protótipo acadêmico criado para o Ideathon 2026 da Fatec Araçatuba.

Nossa proposta é facilitar a procura por transporte escolar e ajudar motoristas a organizar rotas e passageiros.

## O que pode ser demonstrado

**Para as famílias:** pesquisa por endereço, escola e horário, com motoristas fictícios e apoio de serviços de mapas.

**Para os motoristas:** telas e ferramentas de cadastro, rotas, paradas, passageiros e planejamento, conforme o funcionamento de cada recurso.

Nem todas as funções estão concluídas. Os preços, as vagas e os perfis fictícios não representam ofertas reais.

## Como desenvolvemos

Utilizamos React, TypeScript, Supabase, GitHub, Vercel e serviços de mapas.

Também contamos com ferramentas de inteligência artificial para programar, corrigir erros, criar telas e aprender a utilizar essas tecnologias.

As ideias e as decisões do projeto foram discutidas pela equipe.

## Antes de apresentar

Precisamos conferir:

- Se as telas abrem e funcionam no computador e no celular.
- Se os trajetos e horários demonstrados fazem sentido.
- Se as funções que dependem do banco de dados estão configuradas.
- Se os dados fictícios estão identificados.
- Se conseguimos explicar o que funciona e o que ainda precisa melhorar.

## Como executar

Com o Node.js instalado, na pasta do projeto:

```bash
npm install
npm run dev
```

Para verificar a compilação e executar os testes:

```bash
npm run build
npm run test
```

Alguns recursos precisam de configurações adicionais, explicadas no [guia do Supabase](GUIA-SUPABASE.md).

## Próximos passos

Vamos continuar testando as funcionalidades e melhorando a experiência.

O objetivo da apresentação é mostrar a ideia e o que conseguimos aprender e construir, sem apresentar o protótipo como um serviço comercial já disponível.
